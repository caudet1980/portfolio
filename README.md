# Portfolio — Catherine Audet

Personal portfolio built with vanilla HTML, CSS, and JavaScript.

**[Live Demo](https://caudet1980.github.io/portfolio)**

## Features

- Bilingual FR / EN with JSON translation files and language toggle
- Dark mode design with CSS custom properties
- Fade-in scroll animations
- Responsive layout with Bootstrap 5

## Tech Stack

- HTML · CSS · JavaScript
- Bootstrap 5
- JSON (i18n)

## Project Structure

```
├── index.html          # Main page
├── css/
│   └── style.css       # Custom styles and design tokens
├── js/
│   └── main.js         # Language toggle and scroll animations
└── lang/
    ├── fr.json         # French translations
    └── en.json         # English translations
```

## Getting Started

No build step required — open `index.html` directly in a browser or serve with any static file server.
